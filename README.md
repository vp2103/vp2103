## Selected Projects

### 1. Wanderlust: DevSecOps on AWS EKS
A three-tier MERN application taken from commit to production on Kubernetes, with security and quality checks built into the pipeline: Jenkins CI, SonarQube code analysis, OWASP dependency checks, Trivy scanning and ArgoCD GitOps delivery to EKS.
**Stack:** Jenkins · SonarQube · OWASP · Trivy · ArgoCD · Docker · AWS EKS
[View repository →](https://github.com/vp2103/Wanderlust-Mega-Project)

### 2. CI/CD on AWS with Terraform: Jenkins, ECR and EKS
Every push to GitHub builds a Docker image, pushes it to Amazon ECR and deploys it to an EKS cluster. Terraform provisions the network and the cluster: a VPC across two availability zones, Kubernetes 1.31 and a managed node group.
**Stack:** Terraform · Jenkins · Docker · Amazon ECR · AWS EKS · Kubernetes
[View repository →](https://github.com/vp2103/ci-cd-project)

### 3. Enterprise CI/CD: Two Pipelines, One App
A Flask application delivered through both GitHub Actions and Jenkins. Each pipeline builds the image, publishes a uniquely tagged version to Docker Hub and validates it by running the published image and checking the response.
**Stack:** GitHub Actions · Jenkins · Docker · Docker Hub · Python
[View repository →](https://github.com/vp2103/enterprise-ci-cd)
